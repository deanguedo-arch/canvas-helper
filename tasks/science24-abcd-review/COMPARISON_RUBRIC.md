# Science 24 A–D comparison rubric

Use **0–4 with evidence** per dimension: 0 = missing or unsafe, 1 = major gap, 2 = workable but inconsistent, 3 = strong, 4 = exemplar for this course family. A count or a prior report alone earns no score. A confirmed scientific, source, saved-work or essential accessibility failure is a blocker regardless of the average.

| Dimension | Inspect | A strong result shows |
|---|---|---|
| Source fidelity | Objectives, textbook printed/PDF pages, workbook questions/subparts/diagrams, guided notes, omitted pages, original keys, CBE disposition | Complete mapping; source tasks either taught and practised, retained with context, optional, supervised or explicitly corrected; hidden tests excluded |
| Science and currency | Definitions, calculations, diagrams, assumptions, dated health/safety/environment claims, answer keys | Correct method, units and interpretations; outdated claims labelled and checked against current authority; no unsupported certainty |
| Instructional depth | Every lesson opening, how/why explanation, prior knowledge, page guide, synthesis | A learner can build the concept without mandatory video or AI and can explain the mechanism |
| Worked reasoning | Two examples, steps, diagrams/tables, units, limiting assumptions | Examples model transfer rather than repeat the definition or merely reveal an answer |
| Practice and feedback | Error diagnosis, guided/independent tasks, retries, hints, distractors, written work | Varied cognitive demand, plausible errors and feedback that explains the mechanism and repair |
| Required checks | Two objective and two saved explanations, final synthesis, completion action | Valid answers, unambiguous wording, meaningful explanation prompts, distinct from optional practice and original tests |
| Vocabulary | Search/filter, four anchor terms, Frayer blanks, versions, comparison | Unit-specific examples and distinctions; support is useful without pre-filling student work |
| Textbook and workbook | Lesson page link, printed vs physical page, original page view, complete question context, saved numbered work, key guidance | Clean lesson references; original questions accessible in Textbook Practice; drawings/tables not reduced to contextless OCR |
| Figures and diagrams | Source provenance, placement, size, reading prompt, labels, zoom, text wrap/stack | Every figure has a learning job and learner action; readable at phone width; no duplicated or decorative image crowding |
| Video and fallback | Publisher/link, lesson tie, viewing guidance, captions, local written explanation | Optional playback; the lesson remains complete if video is unavailable |
| Design and navigation | Overview, course route, lesson hierarchy, spacing, buttons, cards, dialogs, labels | Pilot 3 level of clarity and one coherent A–D component language, with content-specific layouts |
| Accessibility and responsive use | 390 px, tablet, desktop, 200% zoom, focus, keyboard, long text, dialogs, image alternatives | No clipping; legible source details; discoverable focus and controls; meaningful text equivalents |
| Saving and history | IndexedDB reload, draft/confirmed states, failures, two-tab conflict, previous-draft work | No silent data loss; explicit completion; recovery and earlier work remain distinct and accessible |
| Source ownership and release boundary | Canonical HTML/data, stable IDs, compiled output, metadata and blocked state | Routine content editable at source; runtime surfaces labelled; exact candidate evidence; no local proof misreported as LMS certification |

## Sampling rule

Inspect every unit and chapter, then deep-read at least one lesson per chapter plus the integrated review. Include a calculation or diagram lesson and a health/safety or environmental claim where present. Compare matching UI surfaces at the same viewport; inspect the PDFs when a screenshot or extracted text could hide labels, tables or page context. Record unreviewed routes honestly.

## Finding format

`Priority · Unit/route · Dimension · Evidence file/page/screenshot · Observed behavior/content · Learner impact · Proposed change · Acceptance check · Confidence/remaining verification`
