# Tasks
Workflow:
1) Copy tasks/_template.md into tasks/active.md
2) Fill in Goal + Acceptance Tests
3) Run agent
4) Verify
5) Commit

Tracker guides:
- [Next Step Teacher Tracker README](./next-step-teacher-tracker-readme.md)
- [Google Classroom / Next Step Tracker Review Packet](./google-classroom-review-packet-readme.md)

Recommended starting path:
1) Open the teacher tracker README
2) Start with `Setup / Repair Tracker`
3) Use `Sync Everything` for the normal safe refresh loop
4) Build `Live Proof Checklist` and prove one apply phase at a time on a disposable test course
5) Use review/apply sheets only when you are ready to approve exact rows
