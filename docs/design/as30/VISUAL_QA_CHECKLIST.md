# AS30 Visual QA Checklist

Use this checklist after every Codex implementation pass.

## Desktop Units Home — 1672×941

- [ ] Sidebar width is 336px.
- [ ] Sidebar reaches full viewport height.
- [ ] Sidebar has dark forest/navy background, not flat black.
- [ ] Top pattern band is visible and about 50px tall.
- [ ] Course title reads ABORIGINAL STUDIES 30.
- [ ] Course title is cream, bold, uppercase, and stacked.
- [ ] AS badge is circular and placed to the right of the course title.
- [ ] Active Units nav row is turquoise/teal and visually dominant.
- [ ] Nav includes only Units, Quizzes, Assignments, Library, Film Room.
- [ ] Sidebar footer says Learning. Respect. Reciprocity.

## Progress hero

- [ ] Hero begins around x=382, y=32 at 1672×941.
- [ ] Hero is roughly 1247×274px.
- [ ] Hero uses copper border and rounded corners.
- [ ] Progress track is long, thin, rounded, and patterned.
- [ ] 0% is large, cream, and visually dominant.
- [ ] “complete” sits beside the percent, not below in a generic card layout.
- [ ] 0 / 4 Units appears top-right.
- [ ] Modules: 0 / 4 appears lower-right.
- [ ] Background has dark landscape/topographic feel.

## Unit cards

- [ ] Section heading says UNITS.
- [ ] Four cards are horizontal rows, not generic tiles.
- [ ] Each card is about 108px tall at desktop.
- [ ] Cards have copper borders and dark textured background.
- [ ] Each card has circular T1/T2/T3/T4 badge.
- [ ] Badge column is about 130px wide.
- [ ] Teal/copper vertical accent strip separates badge from text.
- [ ] Theme title uses display/serif-like font and cream color.
- [ ] Subtitle is readable cream-muted text.
- [ ] Copper chevron appears at right.
- [ ] Hover/focus states are visible.
