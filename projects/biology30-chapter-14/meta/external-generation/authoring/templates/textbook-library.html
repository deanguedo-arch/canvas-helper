Textbook Library

This optional library contains the chapter reading used alongside the course. You do not need to open it before starting a lesson. Use the links to explore a topic, then return to the lesson.

How to use the Textbook Library — Follow a page link → read the source → return to your lesson
  1. Use lesson links whenever possible. A textbook link beside a lesson or question opens the chapter at the page connected to that task.
  2. Read the requested printed page. The PDF page number and the textbook’s printed page number are different, so use the printed page shown in the lesson instructions.
  3. Use full screen if the embedded reader is too small. Open chapter full screen creates a larger view. Download chapter saves a copy to your device.
  4. Return to the task. Use the course navigation to go back to the lesson or practice page you were completing.

Remember: the textbook is a reference. Follow the instructions on the lesson or question page to know exactly what to read and what response is expected.
