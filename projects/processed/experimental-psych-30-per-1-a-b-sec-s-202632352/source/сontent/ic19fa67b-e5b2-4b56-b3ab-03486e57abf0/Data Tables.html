Creating Tables to Support Conclusions

In social science research, analytical tables are designed to support conclusions about the relationship between variables.  Frequently, brief descriptions are presented with tables.  Some individuals prefer to read descriptions and barely glance at tables; others prefer to review well-designed tables and ignore the accompanying descriptions.  Because of this, both the table and its descriptive text must be carefully crafted.

Table Description

The titles, headings, and footnotes in tables must convey clearly the general purpose of the table and explain the scaling and coding (if needed).  An effective table allows the reader to draw meaningful conclusions about the relationships among variables. 

Table Creation

Tables can be created using paper and pencil technology or they can be created using spreadsheet software.  Regardless of how a table is created, effective tables must have:

✔️ a title that identifies the variables  (The title is usually in bold type.) 

✔️ correctly labelled columns and rows  (When appropriate, the left column or top row should contain the manipulated variable.  The bottom row or right column should contain the responding variable).

✔️  an "end" right-hand column with the average for each trial, if  applicable units displayed in row or column headings only

✔️ missing values displayed as a dash ( - ) and zeros as 0  (Tables should have no blank spaces).

✔️ numbers aligned appropriately and to the same decimal place, if applicable
