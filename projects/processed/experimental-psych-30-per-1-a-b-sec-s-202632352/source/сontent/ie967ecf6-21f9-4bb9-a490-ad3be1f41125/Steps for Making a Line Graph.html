Steps for Making a Line Graph

  • On graph paper, draw a set of axes (x and y).  Be sure to leave room for titles and headings and use as much of the page as you can when you draw the axes.  (No one likes reading small graphs.)

  • Give the graph a title. 

  • Label the horizontal axis (x-axis) with the manipulated variable.  Add a scale that includes all values of the manipulated variable.  

  • Label the vertical axis (y-axis) with the responding variable.  Add a scale that includes all values of the responding variable. 

  • Plot a point on the graph for each row of data in the table.  When you have plotted all the points, draw a line of best fit.
