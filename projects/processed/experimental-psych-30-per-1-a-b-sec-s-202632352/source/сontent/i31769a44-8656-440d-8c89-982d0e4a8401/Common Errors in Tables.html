Common Errors in Tables

The measurement units of variables must be consistent within any data table.  For example, if you collected data on the volume of tears a person sheds with different types of onions, your raw data might look like the table below.

Onion Type and Tears Produced

Volume of Tears Produced per hour

20 mL

0.15 L

3.0 x 101 mL

1.9 x 10-1 L

18 mL

The table above, although showing the data collected, is a poorly designed table.  The unit for volume should be present in the heading of the column, and all values in the column should be converted to the same unit.  Please review the revised table below.
