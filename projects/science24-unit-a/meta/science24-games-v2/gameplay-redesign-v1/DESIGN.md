# Gameplay redesign, C1 pilot

Historical proposal only. No C1 implementation from this proposal is active. The subsequently accepted gameplay plan starts with the complete B2 pilot and learner-controlled coached openings, then C1 after concrete B2 feedback. Current records: `b2-pilot-1/`. The forced-failure idea below is superseded: correct first attempts must be accepted. Preserved here as design history.

User finding: seven polished games feel dead, confusing and like animated questions. Technical validation does not establish engagement or instructional usability.

Route: Sol lead owns this bounded C1 slice because its source overlaps the current dirty authored game and the change touches prediction, attempts, first transfer and progression. Existing deterministic engine/state functions remain authoritative. No worker call is appropriate for these boundaries. Other seven canonical games and the sealed rc1 ZIP remain preserved.

Mechanic: deploy limited route interventions, commit a plan-specific prediction, test, watch source-to-target consequences, repair the open route, then explain the successful plan. Guided first case requires a one-card trial before a two-card repair. No initially solved screen. Packet animation describes the authored route, not infection probability. Untimed planning and keyboard play; reduced motion shows the same result without travel animation.

Progression: guided kitchen case -> four six-scenario-contract practice tasks -> independent final route case -> evidence review. Original scenario IDs, quantities and pure science checks stay intact. Defence cards are placed into labelled response zones, with immune memory inside adaptive response. Prediction, source classification, route plan and brief explanation are learner actions. First transfer is captured at its first submitted trial; no hints or replay before that trial.

Response history, editing invalidation and backward navigation are preserved. Completion uses the existing model validity and explicit learner reasoning self-review, not a timer score. All explanation quality remains teacher pending.

Build preview only. Prior rc1 technical evidence applies to the preserved ZIP bytes, not the revised canonical C1. Do not overwrite that ZIP or claim the suite is revalidated. Deferred rollout: updated C1 full flow, all seven widths, native/manual checks, exact candidate approval and a newly versioned package after gameplay acceptance. Other games need their own distinct gameplay loop; do not propagate this map UI wholesale.
