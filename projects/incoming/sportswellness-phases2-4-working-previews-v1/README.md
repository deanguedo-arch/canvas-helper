# Open the Sports Wellness previews

Extract the ZIP and open **OPEN_PHASES.html** to choose The Drive, The Focus or The Toolkit. Keep every phase’s `assets` folder beside its `index.html`.

For a stable local review origin, run `python3 start_preview.py`. Stop with Control-C. Use the same browser and launch method for resume checks; make a backup before changing devices or paths.

These are working local learner previews, not SCORM packages. Work saves in the browser only. My Work prints/exports a readable copy; backup/import is in How to use this phase. Neither action submits to Brightspace.

Read **BUILD_HANDOFF.md** for exactly what is included, what was tested and what still blocks student release. The newest uncommitted Phase 1 reference was unavailable. The included theme matches the newest repaired upload, not a certified comparison to that missing local copy.

External videos are withheld pending verification. Core teaching, reading PDFs, activities, diagrams and games are local. The combined `developer` folder contains source maps, answer records, reference decks and tests; it is not a new student course phase.
