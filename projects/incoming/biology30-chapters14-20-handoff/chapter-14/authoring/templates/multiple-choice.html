Multiple choice

Use the mechanism to decide. Do not rely on the position of an answer.

How to use multiple choice
  1. Choose a topic, difficulty and set size. Select Start practice.
  2. Select one answer and check it. A first error gives a cue; a second reveals the answer and explanation.
  3. The first-try result remains in the record even if you correct the answer.
  4. Finish the set, review the record, or retry missed questions.

Stop and reset asks for confirmation before clearing an unfinished run. Completed history is kept. Practice never increases required-check progress.

Questions are drawn from a finite authored bank. Options are shuffled. A resumed set returns in the same order. Narrow filters may provide fewer items than the requested set size.
