Negative feedback opposes the starting change

After a meal, blood glucose rises. The pancreas releases more insulin. Insulin promotes glucose uptake by responsive cells and storage, helping blood glucose fall toward its usual range. As the original rise is corrected, the stimulus for extra insulin release decreases.

This is because the response opposes the starting change. The opposite situation can also use negative feedback: when blood glucose falls, glucagon helps the liver release glucose. The resulting rise opposes the original fall.

An increase is not automatically positive feedback

To identify feedback, compare the response with the starting change. When a value starts too high, a response that lowers it can be . When a value starts too low, a response that raises it can also be negative feedback.

Use three steps: name the starting change, describe the response, and decide whether the response opposes or strengthens that change. “Positive” and “negative” do not mean helpful and harmful.

Positive feedback strengthens the starting change

During labour, the baby pressing against the cervix stretches it. This supports the release of oxytocin. Oxytocin strengthens uterine contractions, which can push the baby more firmly against the cervix and increase the stretch.

The response strengthens the starting change, so this is . It does not continue indefinitely: delivery changes or removes the stretch that maintains the loop. Positive feedback can help complete an event with a clear endpoint.

Practise the comparison before adding more glands

Blood glucose rises → insulin helps lower it: the response opposes the rise, so the feedback is negative. Blood glucose falls → glucagon helps raise it: the response opposes the fall, so the feedback is also negative.

Cervical stretch increases → contractions increase the stretch: the response reinforces the change, so the feedback is positive. Identify the endpoint as well as the reinforcing steps.

For now, explain those relationships in complete sentences. First establish what a normal feedback loop does. Then you can apply the same reasoning to pathways involving several glands.

Worked example

An upward response can be negative feedback

Blood glucose falls. Glucagon helps the liver release glucose, raising blood glucose.

  1. The starting change is a decrease in blood glucose.
  2. The response increases blood glucose toward its usual range.
  3. The response opposes the starting decrease. Therefore this is negative feedback.
