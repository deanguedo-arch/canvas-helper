Crossing over and independent assortment

How can meiosis create different genetic combinations?

Learning goal

Explain crossing over, independent assortment and random fertilization, keeping chromosome sets complete.

Before you begin

Homologues can carry different alleles. Their orientation at metaphase I affects which combinations enter gametes.

Crossing over changes combinations within chromosomes

During I, pair closely. Corresponding segments can be exchanged between non-. Because the homologues may carry different alleles, the exchange can produce chromatids with new combinations of parental variants.

The exchange normally occurs between corresponding regions. It should not be drawn as random loss of large unmatched pieces. A schematic can use two colours to track parental origin, but each resulting chromosome still needs the appropriate set of gene regions.

reshuffles existing information. Mutation is a change in DNA sequence that can produce a new allele; these mechanisms are related to variation but are not the same event.

Different chromosome pairs orient independently

At I, one pair's orientation does not determine another pair's orientation. A gamete can therefore receive a mixture of maternal and paternal homologues. It does not normally receive an exclusively maternal set or exclusively paternal set as a rule.

For n independently assorting chromosome pairs, 2 to the power n gives the number of possible chromosome combinations from assortment alone. For a 2n = 4 model, n = 2, so 2² = 4 possible combinations. This counts types of possible combinations, not the number of cells made by one division.

For humans, n = 23, giving 2²³ = 8,388,608 possible combinations before including crossing over. The number illustrates why chromosome-set organization creates extensive variation.

Fertilization adds another combination step

A sperm and egg then combine by fertilization. Each may carry a different allele combination. , crossing over and together make genetically different offspring possible.

The “independent” model has limits. Genes close together on one chromosome may travel together unless crossing over separates them. Chapter 17 will connect that linkage to inheritance ratios.

When explaining variation, name the mechanism and what it changes. Do not claim a process creates extra chromosome types when it actually rearranges which versions are inherited together.

Worked example

Calculate assortment combinations

A species has 2n = 6 and the three homologous pairs assort independently. Ignore crossing over.

  1. Find n: three chromosome pairs means n = 3.
  2. Each pair has two possible parental orientations relative to a gamete.
  3. Multiply the independent choices: 2 × 2 × 2 = 2³ = 8.
  4. These are eight possible chromosome combinations across possible meiotic events, not eight products from one meiosis.
  5. Crossing over would add further allele combinations beyond this simplified count.
