Worked example

Identify a stage from the stated evidence

Given: A model cell contains two groups of separated chromosomes moving toward opposite poles, and new nuclear envelopes have not formed. Question: Which mitotic stage best fits, and why?

  1. Use the chromosome relationship: the sisters have separated. This is more specific than simply noticing condensed chromosomes, which occur in several stages.
  2. Exclude metaphase: the chromosomes are no longer aligned together at the equator; the given explicitly says the groups are moving apart.
  3. Compare with telophase: the given does not describe chromosomes enclosed by newly forming nuclei. The observed separation and movement best fit anaphase in this model.
  4. Apply the counting consequence: each separated former chromatid is now a chromosome. State whether a requested count covers both groups in the undivided cell or only one pole.

Check: movement is part of the supplied scenario. If you had only an unclear still photograph, you would need visible chromosome/nuclear features rather than assuming motion from the PMAT abbreviation.
