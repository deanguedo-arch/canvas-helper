Count sets before counting copies

A contains one of each chromosome type in the species model. A haploid cell has one set, written n; a diploid cell has two, written 2n. Normal human gametes have 23 chromosomes, and a typical nucleated body cell has 46. The number of sets is its ploidy.

For a model with five types, one set contains five chromosomes. Two sets contain 2 × 5 = 10. If instead the question gives 2n = 10, divide the diploid total by two to recover n = 5. Count matching types and complete sets; chromosome number alone is not a measure of an organism's intelligence or complexity.

Polyploid means more than two complete sets. In the textbook's set-counting model, tetraploid means four sets and octoploid means eight. If one basic set contains five chromosomes, those totals are 4 × 5 = 20 and 8 × 5 = 40. For the optional coffee question, use its supplied one-set value, multiply by the named number of sets and label each result. Its prose and picture list the categories in different orders, so attach each answer to diploid, tetraploid or octoploid rather than relying on position.

Replication is not the addition of a new set of independently counted . It copies each existing chromosome into joined sisters before they are distributed. A diploid cell remains diploid after S phase. The next lesson tracks chromosome number and DNA amount separately so that an X shape does not mislead the count.
