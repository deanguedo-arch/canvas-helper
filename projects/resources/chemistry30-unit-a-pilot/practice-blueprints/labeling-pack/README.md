# Chemistry 30 — Codex Labeling Activity Pack

This pack contains **10 individual student-facing labeling images** with letter markers plus machine-readable answer keys.

## Files

- `chapter_11/` — Chapter 11 images
- `chapter_12/` — Chapter 12 images
- `chapter_13/` — Chapter 13 images
- `label_answer_manifest.json` — preferred source for Codex / the practice engine
- `label_answer_key.csv` — human-readable teacher answer key
- `CODEX_INTEGRATION.md` — implementation guidance

The image itself contains **letters only**. The correct label text is kept outside the image so the activity can randomize answer choices without exposing answers.

## Important

`ch12_half_reaction_representation.png` is tagged as a **structure-only** labeling asset. It should be used to identify the parts of half-reaction notation, not as the canonical example of a specific balanced half-reaction.

All other answer mappings are defined in `label_answer_manifest.json`.
