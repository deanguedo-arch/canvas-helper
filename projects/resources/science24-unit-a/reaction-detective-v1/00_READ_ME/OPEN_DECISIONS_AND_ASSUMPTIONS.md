# Open Decisions and Assumptions

## Assumptions used for this handoff

- First build is a self-contained static practice activity.
- It is intended to work both independently and when linked/embedded from the Science 24 course.
- No LMS gradebook/reporting is required in v1.
- No persistent save is required in v1.
- Desktop and phone-width access are required; no landscape-only assumption.
- The approved visual standard is locked for this build.

## Still needs confirmation before course release

- Exact lesson/check location inside the current deployed Unit A build.
- Whether the game counts toward required course progress or remains optional practice.
- Whether a future teacher-reviewed explanation workflow is wanted.
- Whether later releases require SCORM/LMS persistence.
- Final district hosting path and CSP requirements.
- Teacher/science reviewer sign-off on all six scenario records.

These items do not block a prototype build, but they do block a claim that the activity is fully integrated/released.
