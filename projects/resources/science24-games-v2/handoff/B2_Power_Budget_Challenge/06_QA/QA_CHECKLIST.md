# B2 QA Checklist

## Science/content
- [ ] Independently solve every worked/practice/transfer scenario.
- [ ] Test correct, common misconception, incomplete and valid-alternative responses.
- [ ] Verify units, signs, rounding, counts, route coverage or probability as applicable.
- [ ] Confirm generated context art carries no answer-critical label/value.
- [ ] Teacher content review recorded.

## Learning progression
- [ ] Prediction occurs before reveal/run.
- [ ] Worked solution is unavailable during independent transfer.
- [ ] Supports visibly reduce across the sequence.
- [ ] Prior attempt is retained during revision.
- [ ] Review distinguishes completion, support used and independent transfer.

## Navigation/state
- [ ] Previous/Next works at every stage.
- [ ] Moving backward preserves every field and feedback state.
- [ ] Moving forward restores later work.
- [ ] Editing after success invalidates progression or enters explicit revision.
- [ ] Restart is separate and confirmed.

## Accessibility/runtime
- [ ] Keyboard-only full route.
- [ ] Touch route and 44 px targets.
- [ ] Screen-reader names/focus/status behavior.
- [ ] Text/table equivalent for the scientific visual.
- [ ] Reduced motion and pause/step where needed.
- [ ] 360/390/430/768/1024/1440/1648 widths and 200% zoom.
- [ ] No network calls, analytics or data collection.

## Visual regression
- [ ] 1440×900 screenshots match the baseline within the shared threshold.
- [ ] 390×844 screenshots match the mobile baseline.
- [ ] Exact assets and tokens used; no substitute icon set.
