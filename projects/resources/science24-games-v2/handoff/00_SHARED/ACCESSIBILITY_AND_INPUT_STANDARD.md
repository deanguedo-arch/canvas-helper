# Accessibility and Input Standard

- Every interaction works with keyboard and touch.
- Drag interactions require select-and-place buttons or equivalent controls.
- Sliders require labelled number inputs or step controls.
- Colour is always paired with text, shape or icon.
- Graphs, equations, pedigrees and route maps have readable text/table alternatives.
- Focus order follows the visual task order; focus is never thrown to the top after a local update.
- Feedback uses a dedicated polite status region, not a live region around the whole app.
- Support reduced motion, pause/replay/step-through where animation carries meaning.
- Avoid flashing, reflex scoring, sound-only warnings and unnecessary time limits.
- Test 360, 390, 430, 768, 1024, 1440 and 1648 px widths plus 200% browser zoom.
- Minimum touch target: 44×44 CSS px.
