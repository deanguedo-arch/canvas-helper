# D2 — Crash-Test Studio Production Design Specification

**Status:** PRODUCTION_HANDOFF  
**Unit:** D — Safety in Transportation  
**Tagline:** Control one variable. Compare impulse and force.

## Learning purpose
Run controlled stopping fixtures, change only stopping duration, compare momentum/force ledgers, justify a design, then apply momentum conservation in a cart test.

## Curriculum claims
D3, D4. These are targeted-practice claims, not complete unit coverage.

## Current course placement guardrails
- Chapter 15 — The Physics of Collisions
- Chapter 16 — The Technology of Safety

## Direct exam-preparation demands
- Calculate signed momentum and momentum change.
- Relate impulse to momentum change.
- Compare average force for the same momentum change over different stopping times.
- Keep occupant and vehicle/cart system boundaries separate.
- Apply conservation of momentum to one-dimensional carts that lock together.

## Canonical workspace
**Test Setup / Slow Replay / Momentum & Force Ledger**
