# D2 Acceptance Tests

**Release verdict values:** Pass / Revise / Not tested.

1. A new learner can identify the goal and next action without author coaching.
2. A correct route produces scientifically valid feedback.
3. The most likely misconception produces targeted feedback and a useful next action.
4. An incomplete response is not certified as mastery.
5. A valid alternative is accepted or routed to teacher review.
6. A learner can revisit any prior step and continue without losing work.
7. The transfer task changes context/representation and hides the worked solution.
8. Keyboard, touch and text alternatives support the same reasoning task.
9. The live screen matches its executable mockup and PNG baseline.
10. No student data or network service is used.
