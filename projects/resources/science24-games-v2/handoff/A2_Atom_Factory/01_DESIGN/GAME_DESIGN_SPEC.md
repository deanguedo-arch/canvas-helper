# A2 — Atom Factory Production Design Specification

**Status:** PRODUCTION_HANDOFF  
**Unit:** A — Applications of Matter and Chemical Change  
**Tagline:** Balance particles. Preserve every atom.

## Learning purpose
Factory order puzzle: change whole-particle coefficients, inspect the element ledger, ship only balanced batches, then solve a plain-text equation.

## Curriculum claims
A2, A3. These are targeted-practice claims, not complete unit coverage.

## Current course placement guardrails
- Chapter 2 — Common Reactions
- Chapter 3 — Types of Chemical Reactions

## Direct exam-preparation demands
- Read formulas and count each element separately.
- Distinguish coefficients from subscripts.
- Determine whether an equation is balanced.
- Balance equations with smallest whole-number coefficients while accepting valid multiples.
- Explain conservation using an atom-by-atom ledger.
