Use a model like a scientist

  1. Name the variable. Identify what changes and how it is measured.
  2. Change one condition. Select a stage or scenario deliberately.
  3. Describe the evidence. Record a trend before explaining it.
  4. Connect the mechanism. Use channels, hormones, receptors, or target tissues.
  5. State the limit. Explain what the model simplifies or cannot establish.
