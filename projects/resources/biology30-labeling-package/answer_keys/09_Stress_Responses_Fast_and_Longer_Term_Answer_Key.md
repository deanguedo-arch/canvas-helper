# Stress Responses: Fast and Longer-Term — Answer Key

## 1. Rapid Sympathetic–Adrenal–Medulla pathway
- A — Hypothalamus
- B — Sympathetic nervous system / sympathetic nerve impulse
- C — Adrenal medulla
- D — Epinephrine and norepinephrine

## 2. Hypothalamus–Pituitary–Adrenal (HPA) pathway
- E — Hypothalamus
- F — CRH (corticotropin-releasing hormone)
- G — Anterior pituitary
- H — ACTH (adrenocorticotropic hormone)
- I — Adrenal cortex
- J — Aldosterone
- K — Cortisol
