Which lesson flow works better?

Version A is the current course lesson. Version B has been revised with more teaching, a fully introduced situation and the original course navigation and practice questions. The paired views below show the same five points at desktop and phone width. Open either full page to read and try it.

What changes between A and B

PointVersion A · current wordingVersion B · proposed wording
First step“Make a first decision. Read ‘What would you do?’” There is no matching opening decision in this lesson.“Read the two documents.” The guide links to an explanation of job postings, the job notice and Rowan’s preparation notes. It also names the six practice questions.
Rowan’s contextThe source stop asks “Which action in Rowan’s supplied record…” before the record appears.“Rowan is applying for a first job.” The opening explains the library’s need, what an application is, Rowan’s background and the learner’s role in writing as Rowan.
Reading the documentsA posting and experience record appear together with little explanation of what each document is.Students learn what a posting tells them, read a job notice and answer a reading question. Rowan’s notebook is then introduced as preparation notes, with the situation, action and outcome explained for each entry.
Worked exampleThe example presents the matching parts and a finished statement.The writer explains why a duty needs a particular skill, quotes a matching action, builds the response, and checks it against the original facts.
External source“Required source stop” and a checkbox before the case. The final task requires a dated source detail.A collapsed “Skills for Success · optional reference” sits with the guide and vocabulary. It links to the official skill descriptions; the supplied documents complete the task.
Practice model“Result: Rowan asked the staff adviser before changing the record.” Asking is an action; the record does not give a finished list.The record says the adviser obtained the missing forms and Rowan then updated the list with verified names. The model uses that stated result and invites revision.
Independent workThe festival task requires a Skills for Success detail and date alongside the application sentence.“Write Rowan’s application response”: select a festival duty, then write one or two sentences from the new fundraiser notes, using the stated success criteria.
