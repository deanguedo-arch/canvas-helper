p  :: Learn the basics

h3 ce1-02-foundations-title :: Know what an occupation profile can tell you

p ce1-02-foundations-purpose :: Career websites contain several kinds of information. Before reading the profile and employer notice, learn which question each kind can answer. This will help you compare work with a person’s interests and preferred conditions.

h3 ce1-02-foundation-heading-1 :: Distinguish a job, an occupation and a career

p ce1-02-foundation-copy-2 :: A job is a particular position with an employer. An occupation groups work with similar duties. A career is a longer path that may include several jobs, learning and other life roles. An occupation profile describes a kind of work across settings. A job posting advertises a particular opening.

p ce1-02-foundation-copy-3 :: A National Occupational Classification, or NOC, code identifies an occupational group used in Canadian information. It helps you check whether sources cover the same group. It is not a ranking of people or a guarantee that every job in that group has the same conditions.

h3 ce1-02-foundation-heading-4 :: Sort a statement before using it

p ce1-02-foundation-copy-5 :: A duty says what someone does. A working condition says when, where or under what demands. Preparation describes education, experience or other evidence used to enter the work. In a simple notice, “prepare notices” is a duty, “evening shifts” is a condition and “bring examples of your writing” describes preparation.

p ce1-02-foundation-copy-6 :: Read in three passes: find the relevant field, explain its fact in your own words, then state what it supports and leaves open. Keep the publisher, place and dates attached. “Common” and “preferred” describe different strengths of statement from “required.” An access date tells you when a page was read; it does not make an older section newly updated.

p ce1-02-foundations-reading :: When you read the case: Use the profile for broad information and the posting for that employer’s opening. Before the first reading check, identify whether the sentence describes work, working conditions, preparation or the source itself.

p  :: Use the method with the case

h3  :: Begin with the work, not a title

p  :: A job is a particular position with an employer. An occupation groups work with similar duties. A career is a longer path that may include different jobs, learning and other life roles. Jordan could hold a layout job while exploring the broader graphic-design occupation; neither would determine every later career choice.

p  :: A career cluster is a useful way to group related work for exploration, such as work involving visual communication. A classification system has a different purpose: it organizes occupations so sources can describe or compare them consistently. Canada's National Occupational Classification, or NOC, assigns codes to occupational groups. A code helps you check that two sources concern the same group. It is not a personal ranking or a guarantee that all jobs in the group have identical duties.

h3  :: Sort what each sentence can establish

p  :: A duty answers, “What would I do?” A working condition answers questions such as, “When, where or under what demands?” Preparation concerns learning, experience or credentials used to enter the work. These categories answer different parts of Jordan's question. An appealing duty does not answer a concern about evening work.

p  :: Be attentive to words such as common, some, preferred and required. If some employers prefer experience, that is narrower than a rule that every applicant must have it. A broad profile's preparation summary is not a particular program's admission decision. A credential is a formal record of qualification; a portfolio is a selected collection of work showing what someone can do. They are different kinds of evidence.

h3  :: Keep the source attached to the claim

p  :: Read a source in three passes: locate the relevant field; state the fact in your own words; explain what it supports and what it leaves open. Preserve the date and scope. An update date indicates when a section was revised. A retrieval date says when you accessed it. Accessing an older section today does not turn it into a newly updated section.

h3  :: Disagreement can reveal a better question

p  :: A broad profile may mention deadline overtime while one posting mostly lists weekday hours. These statements can both be true. They concern different levels of detail. Do not average them or ignore the inconvenient one. Ask what the particular employer expects during busy periods. In this course, the supplied posting answers part of that question without requiring a real conversation.

p  :: Optional first-step hint: Highlight mentally the action words in a sentence. “Prepare drafts” is a duty. “On Saturday” changes the condition under which the duty occurs.

p  :: What is a worked example? An answer that is already completed, with the decisions or calculations explained. As you read, connect the answer to the records; you do not need to copy it.

p  :: A research note explains what a record supports and what still needs checking. An occupation profile covers a kind of work; one posting describes one opening. Their different scopes matter when you compare them.

p  :: I start with Jordan's interest in visual problem solving, then choose the duties field in the Graphic Designer profile. Preparing visual solutions gives a reason to explore the occupation. I have a match between an interest and a task category; I do not yet have evidence that Jordan can do every professional task.

p  :: Next I check the schedule concern. The Graphic Designer profile warns that deadlines can affect hours. The fictional posting makes that issue concrete: it includes a possible Saturday shift before the festival. A regular weekday pattern therefore does not establish that weekends are always free.

p  :: Completed research note: “Graphic design is worth investigating because its visual-solution work relates to Jordan's interest in arranging information. The Graphic Designer profile is an Alberta profile, with relevant sections updated March 22, 2023 and retrieved September 28, 2026. It also indicates that deadlines can affect hours. Prairie Print Studio's fictional posting includes a possible Saturday shift, so Jordan should not assume every job has a predictable weekday-only schedule. The next useful question is how often a particular opening changes its hours. Jordan also needs to investigate portfolio expectations before applying.”

p  :: The alternative “Jordan likes posters, so this job definitely fits” skips both the schedule and preparation. “No designer ever has regular hours” is also unsupported: the record describes possibilities, not every workplace. A careful conclusion keeps the promising connection and the remaining question together.
