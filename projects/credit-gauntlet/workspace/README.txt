Credit Gauntlet — standalone HTML checkpoint v0.2.0

Open index.html to play. Scripts, calculations, fonts and art are all local.
Fresh play starts at the title menu. A saved run opens the main menu with Continue.
Menu is available throughout the game; opening it pauses repayments.
How to Play describes the ten-screen journey. New Game requires a confirmed reset.
Optional cost choices and strategy predictions give feedback, never a score or grade.

The current presentation follows the supplied CALM pixel game screens, not the earlier simplified PDF.
All forty original production PNG files are unchanged. Additional decorative logo/landscape/vehicle regions
are extracted from the supplied image sheets. Financial values, charts and controls are live HTML.
Pixelify Sans is locally bundled under the SIL OFL (assets/fonts/PixelifySans-LICENSE.txt).
DejaVu Sans is used for body text and readable financial numbers; its license is beside the fonts.

Source: index.html, presentation.css, game.js, model.js. styles.css styles the review tools.
compare.html shows the three supplied CALM game references next to the live rendered layouts.
asset-review.html displays all forty original production assets. phone.html provides a narrow preview.

Saving is isolated to credit-gauntlet:standalone:v1. Earlier v1 saves remain compatible and restore paused.
Money is integer cents; the engine retains its original model version. No existing CALM data is read.
The activity is fictional financial instruction with no random events, score, lives or countdown.
Finish after payoff records completion only; replay retains completion.

This is a Build-mode HTML checkpoint for review, not an accepted release or SCORM package.
Full source-fixture, accessibility, portability and route-wide release gates remain in the project handoff.
No build, package install, external service or internet connection is required to play.
