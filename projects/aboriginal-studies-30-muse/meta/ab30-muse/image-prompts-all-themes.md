# Image prompts — all themes (for the Meta model API)

Copy-paste each block as the prompt. Global rules are baked into every
prompt; the per-image notes (alt text) are for course integration, not
the model. All subjects are landscapes, objects, and abstractions:
nothing depicts a real person, a historical event, or a documentary
claim. Every image ships in the course labeled as illustration with the
suggested alt text.

## Global style suffix (append to every prompt)

`muted editorial illustration, gouache and watercolor texture, restrained
earth-tone palette, soft light, no people, no faces, no text, no letters,
no logos, no watermarks, no photorealism`

Global negative: `photograph, real person, face, handwriting, text,
watermark, logo, flag emblem, map with borders, violence, suffering`

Sizes: request 16:9 for lesson headers, 4:3 for source cards.

## Integration notes (course side, not the model)
- Stage approved files under the copy's workspace assets with creator
  `Meta model API generation` + date, and record each in the lesson's
  figure block with the alt text above.
- Figures need teacher review before they count as reviewed media under
  the course figure contract; update the batch suites (which currently
  assert figure-free lessons) when figures land.
- If a render comes back with text-like marks, faces, or emblems,
  discard it rather than editing around the defect.
