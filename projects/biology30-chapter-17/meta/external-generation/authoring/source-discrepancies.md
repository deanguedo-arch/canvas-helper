# Chapter 17: scientific and source reconciliation

These are developer records, not student-facing lesson commentary.

Complete dominance, independent assortment and full penetrance are explicit model assumptions, not universal statements. Real human eye colour and tongue rolling are not asserted to be single-locus dominant/recessive traits. Conditional and joint sex-linked probabilities use different denominators. Pedigrees constrain possibilities rather than proving an inheritance mode from appearance alone. Recombination frequency has a 50% observational ceiling in the standard two-locus model; map distance is not a universally fixed physical number of bases. Sample size and multiple crossovers limit conclusions. Source questions with inconsistent genotype/pedigree premises were adapted explicitly in the assessment ledger. The personal-family pedigree collection on p. 615 is not assigned.
