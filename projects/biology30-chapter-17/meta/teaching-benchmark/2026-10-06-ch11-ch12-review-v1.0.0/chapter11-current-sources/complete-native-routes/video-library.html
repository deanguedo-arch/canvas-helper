Video Library

All videos from the supplied Chapter 11, linked to their teaching or optional extension page.

How to use the Video Library — Choose a video → read the viewing prompt → watch → return
  1. Choose one video. Use the menu below. The selected video card is the only one shown.
  2. Read “As you watch” first. It tells you which Chapter 11 idea to look for. You are not expected to memorize every detail in the video.
  3. Pause and explain. Stop after an important step, diagram or example and explain how it connects to the lesson in your own words.
  4. Use the backup link if needed. If the player does not work, select Watch on YouTube or use the written explanation in the connected lesson.
  5. Return to the lesson. Use the link beneath the video card to go back to the page where the video belongs.

Remember: videos support the lesson reading. Watching a video does not complete a required chapter check.
