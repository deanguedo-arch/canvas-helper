Labeling

Connect a structure’s name with its position and function.

How to use labeling
  1. Choose a diagram. One selected diagram is shown at a time.
  2. Select Start, then choose a structure for each letter.
  3. Use Check beside one label or Check all labels.
  4. Check every current response before selecting Submit and finish. A perfect score is not required; your attempts are recorded.
  5. Use View larger for detail and return to the teaching figure when needed.

This is formative practice. It does not change required-check progress.
