# Source-teaching trial integration boundaries

These are proposed teaching replacements only. Native source is unchanged. The optional-note interface uses the existing S.notes namespace, draft/collection behavior, failure protection and All My Work/print flow. No JavaScript, CSS, storage schema, progress counter or save-gating implementation is supplied. Exact fragment controls remain present; new notes stay optional and ungraded.

NOTE_TITLE_REGISTRATION_PROPOSAL.json records a separate append-only insertion into course-data.notes for friendly All My Work titles. Six original entries remain exact. The metadata stays blocked/proposal-only until authorized integration. No header text, required assessment, reader, vocabulary, media, footer, history or canonical file is altered.

The teacher HTML and teaching-only Markdown retain visibly disabled note textareas and Save response buttons. These previews do not save, reload or connect to All My Work. Markdown uses raw disabled HTML controls so the complete in-place interface survives conversion. Hint/model disclosures are voluntary, not saved or automatically unlocked. Native save/reload/All My Work/print and failure-path checks remain pending after integration; static source compatibility does not establish working UI.
