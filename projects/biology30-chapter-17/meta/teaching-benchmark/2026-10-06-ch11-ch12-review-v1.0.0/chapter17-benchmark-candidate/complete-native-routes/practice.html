Flash cards

Recall first. Reveal only after you have tried to explain the term.

How to use flash cards
  1. Choose a topic and set size, then select Start practice.
  2. Say or write the meaning before selecting Reveal.
  3. Choose I recalled it or Study again. This is self-assessment, not an automatically graded answer.
  4. Continue through the set, then select Submit and finish.

Stop and reset asks for confirmation before clearing an unfinished run. Completed history is kept. Practice never increases required-check progress.

Questions are drawn from a finite authored bank. Options are shuffled. A resumed set returns in the same order. Narrow filters may provide fewer items than the requested set size.
