## Explanatory review

Compare relevant actual Chapter11 passages, not headings or a box count. Check motivation, first-use definitions, smallest sufficient prerequisites, connected causal reasoning, visual reading, explained operations and interpretation, purposeful guided help and genuinely changed inference.

For each activity, read stimulus → learner action → hint → model/criteria → explanatory feedback. Essential instruction must already be visible. Check missing reasoning, prerequisite jumps, repetition, unnecessary qualifications, formulaic practice, hidden-feedback dependence and presentation drift. No word-count target or fixed practice quota.

## Native interaction review

On the disposable QA origin, exercise every new response activity separately: visible stimulus, actual input, explicit Save response, reload, All My Work collection, hint/model disclosures, explanatory feedback and required progress unchanged. Use clearly marked synthetic QA responses. Do not enter synthetic work in Dean’s review origin.

Verify protected assessments/configuration, native IDs/edit keys, runtime/storage logic, CSS/fonts, reader/vocabulary/labeling and all other files. Check desktop and actual narrow browser viewport screenshots, readable tables/figures, response controls and disclosures. A screenshot alone does not prove saving.

## Stop conditions

Any unresolved source-method drift, wrong science, copied required response, untaught task demand, incomplete interaction or modified protected owner blocks readiness. Passing code checks is not teaching certification. Record exact hashes and current sample binding before asking Dean to accept or revise. Keep canonical course files and older comparisons untouched.
