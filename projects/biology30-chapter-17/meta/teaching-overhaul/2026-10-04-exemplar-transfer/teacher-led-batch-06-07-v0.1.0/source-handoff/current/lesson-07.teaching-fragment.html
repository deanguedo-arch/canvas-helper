Population diversity is not individual copy number

A population can contain many versions of a . Each diploid individual still usually inherits two alleles at an autosomal locus, one from each parent. refers to the range of versions in the population, not three or more copies in every individual.

The simplified ABO model uses IA, IB and i. IA contributes A antigen expression; IB contributes B antigen expression; i does not produce either A or B antigen in this model. IA and IB are codominant, and each is dominant over i.

Connect each phenotype to possible genotypes

Type A can be IAIA or IAi. Type B can be IBIB or IBi. Type AB is IAIB, and type O is ii in the standard model. The phenotypes A and B leave uncertainty unless additional family information is available.

An individual with type B and a type O parent must have inherited i from that parent. Therefore the type B individual's genotype is IBi. This is the same constraint reasoning used in a .

Use clear notation. IAIB represents two alleles of one gene, not four separate genes. In plain text, write IA and IB consistently and keep the pairs grouped.

Calculate from the actual cross

For IAi × IBi, possible offspring genotypes are IAIB, IAi, IBi and ii, each with 1/4. The four ABO phenotypes are therefore each possible with probability 1/4 in this specific cross.

A different cross gives different predictions. IAIA × IBi produces IAIB and IAi, each with probability 1/2; no ii offspring is possible because the first parent cannot contribute i.

These models teach inheritance and probability. Real blood typing includes additional factors and rare variants. Do not use a classroom square as a clinical transfusion rule or as definitive proof of family relationships.

Worked example

Use family information before the square

A type B parent has a type O father. This parent has a child with a type AB partner. Find the probability of type O.

  1. The type O father is ii and supplies i, so the type B parent is IBi.
  2. The AB partner is IAIB and can supply IA or IB, but not i.
  3. An O child would require ii.
  4. Because one parent cannot supply i, the probability is 0 in the simplified model.
