Read the explanation

Type A can be IAIA or IAi. Type B can be IBIB or IBi. Type AB is IAIB, and type O is ii in the standard model. The phenotypes A and B leave genotype uncertainty unless additional family information is available. An individual with type B and a type O parent must have inherited i from that parent. Therefore the type B individual's genotype is IBi. This is the same constraint reasoning used in a test cross. Use clear notation. IAIB represents two alleles of one gene, not four separate genes. In plain text, write IA and IB consistently and keep the allele pairs grouped.
