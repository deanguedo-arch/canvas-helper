Fill in the blanks

Use each sentence to recall a nervous-system term. Your attempts and time are saved, but this practice does not affect your lesson-check mark.

How to use fill-in-the-blanks — Choose a set → type → check → finish or reset
  1. Build your set. Choose one lesson or All Chapter 11, choose the number of items and select Start new set.
  2. Read the whole sentence. Use its meaning to identify the missing biology term. Type the term, then check your answer.
  3. Use feedback to learn. If the first answer is incorrect, read the cue and try again. After another incorrect attempt, study the displayed answer and explanation before moving on.
  4. Complete the set. Respond to every item and finish the activity to add the completed run to All My Work.
  5. Starting over is optional. Stop and reset clears only the unfinished set after confirmation. Earlier completed work remains.

Saving: your generated questions, answers, feedback and time save in this browser. This practice does not change chapter-check progress.
