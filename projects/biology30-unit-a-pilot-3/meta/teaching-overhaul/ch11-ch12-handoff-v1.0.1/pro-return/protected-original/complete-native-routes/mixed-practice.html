Mixed practice

Combine retrieval, comparison, application, sequencing and error correction. This formative practice does not affect required chapter-check progress.

How to use mixed practice — Choose a set → follow each prompt → finish or reset
  1. Build your set. Choose one lesson or All Chapter 11, choose the number of items and select Start new set.
  2. Check the task type. Each item may ask you to recall, compare, apply, sequence or correct an error. Read the entire prompt before answering.
  3. Respond and use the feedback. Give your best answer first. If you receive a cue, use it for another attempt. Read the explanation before moving to the next item.
  4. Complete the set. Finish every item and end the activity so the completed run appears in All My Work.
  5. Reset only if you want to discard the unfinished set. Confirmation is required, and completed history is kept.

Saving: the exact set, answers, feedback and elapsed time save in this browser. Mixed practice does not change chapter-check progress.
