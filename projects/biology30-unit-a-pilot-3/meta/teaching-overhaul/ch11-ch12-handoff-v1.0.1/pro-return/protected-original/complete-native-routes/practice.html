Flash cards

Practise recalling eight key nervous-system terms. Your attempts and time are saved, but this practice does not affect your lesson-check mark.

How to use flash cards — Choose a set → recall → reveal → finish or reset
  1. Build your set. Choose one lesson or All Chapter 11, then choose how many terms you want. Select Start new set.
  2. Try to recall first. Read the term and say or think of its meaning before revealing the answer.
  3. Report honestly. Select I recalled it if your meaning was accurate. Select Study again if you missed it or were unsure. This is self-assessment, not an automatic mark.
  4. Complete the set. Continue through every card and finish the activity so the completed run appears in All My Work.
  5. Starting over is optional. Stop and reset clears only the unfinished set after you confirm. It does not erase previously completed runs.

Saving: the exact set, your choices and elapsed time save in this browser. An unfinished set resumes when you return. Flash cards do not change chapter-check progress.
