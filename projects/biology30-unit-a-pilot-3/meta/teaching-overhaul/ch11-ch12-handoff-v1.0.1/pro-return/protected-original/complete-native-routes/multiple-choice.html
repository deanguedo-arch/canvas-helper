How to use multiple choice — Choose settings → answer → learn from feedback → finish
  1. Build your set. Choose a topic, difficulty and number of questions. Select Start practice. A narrow topic and difficulty may produce fewer questions instead of repeating one.
  2. Answer before checking notes. Choose the best option and submit it. Your first answer is recorded as the first-try result.
  3. Use the feedback. A first incorrect answer gives you a cue. Try again. After a second incorrect attempt, read the answer and explanation before continuing.
  4. Complete the set. Continue until every question is finished, then finish the activity so it appears in All My Work.
  5. Reset only when you want a fresh start. Stop and reset removes the unfinished set after confirmation and keeps completed history.

Saving: the exact questions, option order, responses and time save in this browser. This is formative practice and does not affect the 12 required checks.
