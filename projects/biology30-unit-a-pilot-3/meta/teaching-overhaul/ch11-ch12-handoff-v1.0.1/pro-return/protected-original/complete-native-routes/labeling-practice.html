Labeling

Choose a diagram and identify its labelled structures or processes. Each activity saves its own attempts and time, but this practice does not affect your chapter-check progress.

How to use labeling — Choose a diagram → start → label and check → submit
  1. Choose a diagram. Use the menu below to select the structure or process you want to practise. Each diagram keeps its own work.
  2. Start the selected activity. Select Start before choosing labels. The timer begins and the answer controls become available.
  3. Follow each letter carefully. Trace the leader line to the structure, choose a label from its menu and select Check. You can also use Check all labels after making several choices.
  4. Correct and recheck. Read the feedback, change any incorrect label and check it again. Attempt every label before submitting.
  5. Finish or reset. Submit and finish records the run in All My Work. Stop and reset clears only the unfinished diagram after confirmation.

Saving: selected labels, attempts and elapsed time save in this browser. Labeling is optional practice and does not affect the 12 required checks.

The upper sensory neuron carries information from the skin toward the central nervous system. An interneuron connects the pathway within the central nervous system. The lower motor neuron carries the response toward the muscle. Other letters identify the cell body, dendrites, axon, myelin sheath and a node of Ranvier.
