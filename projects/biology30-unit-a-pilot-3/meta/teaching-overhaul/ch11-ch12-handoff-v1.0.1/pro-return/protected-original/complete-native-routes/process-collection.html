All My Work

Review your submitted answers, first-try marks, retries and elapsed time. These are local records, not Brightspace submissions.

How to use All My Work — Review completed work → expand details → print or save as PDF
  1. Check the summary. The page reports how many activity runs you have completed. Unfinished activities are saved separately and do not appear here until you submit them.
  2. Find the run you want. Each completed run shows the activity name, date, elapsed time and number of submitted attempts.
  3. Review the details. Open Review every submitted answer to see each prompt, your response, feedback and first-try information where available.
  4. Review vocabulary separately. My Frayers contains the vocabulary records you added to the collection.
  5. Keep a copy. Select Print or save as PDF, then choose your printer or Save as PDF in the print window.

Important: these records are stored in this browser. They are not Brightspace submissions and may not be available on another device or after browser data is cleared.
