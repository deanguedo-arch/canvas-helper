# Biology 30 neural-pathway activity handoff

This package is for creating a replacement for the Chapter 11 labeling activity in Biology 30 Unit A Pilot 3.

## What to do

1. Upload this entire ZIP to ChatGPT Pro.
2. Open `PROMPT_FOR_CHATGPT_PRO.md` and paste its full contents into the same conversation.
3. Ask ChatGPT Pro to use image creation for the new diagram and to return the complete file set listed in the prompt.
4. Download the returned files as a ZIP without renaming the required files.
5. Give that returned ZIP back to Codex with this instruction: `Integrate this returned neural-pathway activity into Biology 30 Unit A Pilot 3, preserving the existing labeling activity and saved-answer IDs.`

## Package contents

- `source/reference-label-neurons.png` — the current 380 × 270 reference image.
- `answer-key.json` — the verified five-label answer bank and existing integration IDs.
- `PROMPT_FOR_CHATGPT_PRO.md` — the complete design and build request.

The current course remains the canonical source. This package is a design handoff only and must not be treated as a course export.
