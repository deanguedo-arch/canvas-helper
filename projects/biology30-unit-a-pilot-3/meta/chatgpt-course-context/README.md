# Biology 30 Pilot 3 course-context package

This package gives ChatGPT Pro a current visual and structural reference for Biology 30 Unit A Pilot 3, Chapter 11. It also includes the separate neural-pathway activity brief that asks for a new image and interactive prototype.

## How to use this package

1. Upload the complete `biology30-pilot3-chatgpt-course-context.zip` file to ChatGPT Pro.
2. Ask it to open and follow `PROMPT_FOR_CHATGPT_PRO.md`.
3. Let it inspect the screenshots first, then the nested SCORM ZIP for implementation context.
4. Have it follow the nested `biology30-neural-pathway-chatgpt-pro.zip` brief when creating the replacement neural-pathway model.
5. Return ChatGPT's resulting ZIP to Codex with: `Integrate this returned neural-pathway activity into Biology 30 Unit A Pilot 3, preserving the existing activity and saved-answer IDs.`

## What is included

- `screenshots/` — five current course views showing desktop, mobile, a lesson, and the labeling activity.
- `COURSE_STRUCTURE.md` — a compact map of the current learner experience and visual system.
- `PROMPT_FOR_CHATGPT_PRO.md` — the ready-to-paste design request.
- `packages/biology30-unit-a-pilot-3-scorm-2004.zip` — a valid SCORM 2004 structural snapshot of the current course.
- `packages/biology30-neural-pathway-chatgpt-pro.zip` — the focused reference image, answer key, activity instructions, and return checklist.

## Important boundary

The SCORM package is supplied so ChatGPT can understand the current course structure, layout, styling, assets, and interaction patterns. It is a review snapshot, not an LMS-certified release. Save/resume and timing support are present, but required completion and progress measurement are not connected. Chapter 11 is the active learner scope.
