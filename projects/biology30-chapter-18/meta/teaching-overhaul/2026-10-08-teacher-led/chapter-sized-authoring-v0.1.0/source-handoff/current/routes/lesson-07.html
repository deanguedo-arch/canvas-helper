Before you begin

Key terms

Words for this lesson

Use these definitions when you need help with a term.

The complementary strand reported in the opposite displayed order so that it is written 5′ to 3′.
The ordered amino acids in a peptide or protein.

Checking molecule identity, direction, pairing and code interpretation against explicit rules.

Write the problem’s identity line first

Before changing any letters, write four things: the supplied molecule, its strand identity if it is DNA, the displayed direction, and the requested output. “DNA” alone is insufficient when a question expects an unambiguous sequence.

For coding DNA written 5′ to 3′, replace T with U. For template DNA written 3′ to 5′, construct the complementary RNA from left to right. For template DNA written 5′ to 3′, the RNA must be constructed from the template’s opposite end and reported 5′ to 3′.

Keep the direction labels visible until the final check. Removing them early is a common reason for getting correct pairings in the wrong order.

Establish the frame before translating

For a complete simplified message, begin at the specified start AUG and stop at the first in-frame . Divide the sequence into triplets only after establishing the start. Bases before the start are not automatically translated.

For an explicitly stated internal , use the supplied . Such an exercise can ask for amino-acid identities without including the beginning of the protein. Do not invent a start or stop that the question does not provide.

A stretch coding for five amino acids contains fifteen coding nucleotides. An additional stop requires three more nucleotides but does not add an amino acid. State whether the question includes that signal.

Check the result in both directions

Compare each RNA base with the template and compare the RNA with the coding DNA partner. Then consult the codon table one triplet at a time. Check that a stop has not been counted as an amino acid.

Several RNA sequences can produce the same peptide because of code redundancy. From a protein sequence alone, you can often give a possible RNA sequence, but not a unique original sequence.

The short sequences in these exercises are constructed teaching examples, not complete human genes or laboratory protocols.

Worked example

Handle a template supplied 5′ to 3′

Template DNA is 5′-TTA CCC TTT CAT-3′. Find mRNA 5′ to 3′ and translate from its start.

  1. Reverse the template’s displayed order before constructing the 5′ to 3′ RNA.
  2. Complement the reversed template: the RNA is 5′-AUG AAA GGG UAA-3′.
  3. Group from AUG: AUG / AAA / GGG / UAA.
  4. The chain is Met–Lys–Gly; UAA stops translation.
  5. Check that the RNA pairs antiparallel with the original template.
